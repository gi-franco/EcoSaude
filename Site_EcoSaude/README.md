# 🌱 EcoSaúde

**EcoSaúde — Informação e sustentabilidade para uma comunidade mais consciente.**

## 📖 Sobre o projeto

O EcoSaúde é um site desenvolvido para incentivar práticas sustentáveis e facilitar o acesso a informações sobre o descarte correto de resíduos. A proposta é reunir conteúdos educativos e recursos úteis para ajudar a população a cuidar do meio ambiente e da saúde coletiva.

Além de informar, o projeto busca aproximar a comunidade de iniciativas de reciclagem e descarte responsável.

## 🎯 Objetivos

* Conscientizar a população sobre a importância da sustentabilidade.
* Ensinar como separar e descartar diferentes tipos de resíduos.
* Facilitar a localização de ecopontos.
* Incentivar hábitos que contribuam para a preservação ambiental.
* Reunir informações úteis em uma plataforma acessível.

## ✨ Funcionalidades

* **Conteúdo educativo:** informações sobre reciclagem, resíduos e sustentabilidade.
* **Orientações de descarte:** explicações sobre diferentes categorias de materiais.
* **Mapa de ecopontos:** visualização de pontos de descarte em um mapa interativo.
* **Localização:** recursos para ajudar o usuário a encontrar pontos próximos, quando disponíveis.
* **Interface responsiva:** organização do conteúdo para facilitar a navegação em diferentes dispositivos.

## 🛠️ Tecnologias utilizadas

* **HTML5:** estrutura das páginas.
* **CSS3:** aparência e organização visual.
* **JavaScript:** funcionalidades e interatividade.
* **Leaflet:** biblioteca utilizada para exibir o mapa.
* **OpenStreetMap:** dados cartográficos utilizados na visualização do mapa.
* **Netlify:** plataforma para publicação do site.

## 🚀 Como executar o projeto

Para que o mapa interativo do EcoSaúde funcione corretamente, é necessário abrir o projeto utilizando o **Visual Studio Code** e executar o arquivo `index.html` pelo **Live Server**.

### 1. Abra a pasta do projeto

Abra o Visual Studio Code e selecione:

**File → Open Folder** (Arquivo → Abrir Pasta).

Escolha a pasta principal do EcoSaúde, onde estão o arquivo `index.html` e as pastas `css` e `js`.

### 2. Inicie o Live Server

No explorador de arquivos do VS Code, clique com o botão direito sobre o arquivo `index.html` e selecione **Open with Live Server**.

Caso essa opção não apareça, instale a extensão Live Server pela aba de extensões do VS Code.

### 3. Acesse o site

O navegador será aberto automaticamente. No ambiente de desenvolvimento utilizado, o endereço é:

[http://127.0.0.1:3000/index.html](http://127.0.0.1:3000/index.html)

Se o navegador não abrir automaticamente, copie o endereço exibido pelo Live Server e cole-o na barra de endereços.

### 4. Verifique o funcionamento

Após abrir o site, confira se o mapa interativo é exibido corretamente. Caso o navegador solicite permissão para acessar sua localização, permita o acesso para testar os recursos de geolocalização.

> **Importante:** não abra o `index.html` diretamente pelo explorador de arquivos do Windows. Utilize o Live Server para executar o projeto por um servidor local. A porta do endereço pode variar conforme a configuração do servidor.

**Observação:** o endereço `127.0.0.1` funciona apenas no computador em que o servidor está sendo executado. Para disponibilizar o EcoSaúde publicamente, é necessário publicar o projeto em uma plataforma de hospedagem, como o Netlify.

## 🌎 Impacto socioambiental

O EcoSaúde busca contribuir para a educação ambiental por meio da informação acessível e do incentivo ao descarte correto de resíduos. Ao facilitar o acesso a orientações e à localização de ecopontos, o projeto pretende estimular atitudes responsáveis e fortalecer a participação da comunidade na preservação do meio ambiente.
